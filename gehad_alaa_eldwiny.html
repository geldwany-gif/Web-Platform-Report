لغة CSS واستخدامها في تطوير صفحات الويب

اسم الطالب: جهاد علاء الضويني

الرقم الجامعي:2502211

المقرر: تطبيقات الإنترنت والمنصات الإلكترونية

مقدمة البحث

أصبح الإنترنت من الأشياء الأساسية التي نستخدمها كل يوم، وتوجد عليه مواقع كثيرة تقدم خدمات ومعلومات مختلفة. ولكي يكون الموقع سهل الاستخدام ومنظمًا، نحتاج إلى أدوات تساعدنا في ترتيب شكل الصفحات، ومن أهم هذه الأدوات لغة CSS.

تعريف لغة CSS

CSS هي لغة تنسيق تستخدم مع HTML لتحديد الشكل الذي تظهر به صفحة الويب. ويمكن من خلالها التحكم في الألوان والخطوط والخلفيات والمسافات بين العناصر، مما يساعد على ظهور الموقع بصورة منظمة.

كيف تساعد CSS في تصميم المواقع؟

عندما نقوم بإنشاء صفحة باستخدام HTML تكون الصفحة عبارة عن محتوى مثل النصوص والعناوين والصور. وتأتي CSS لتساعدنا في تنسيق هذا المحتوى، مثل تغيير لون العنوان أو تكبير الخط أو تحديد مكان الصورة داخل الصفحة.

أهم مميزات CSS

  • تساعد على تحسين شكل صفحات الإنترنت.
  • تجعل محتوى الموقع أكثر ترتيبًا.
  • تسهل تغيير التنسيق في أكثر من صفحة.
  • تساعد في التحكم في حجم الخطوط والألوان.
  • تجعل التعامل مع الموقع أكثر سهولة.

بعض خصائص لغة CSS

اسم الخاصية وظيفتها
Color تغيير لون الكتابة
Font-family اختيار نوع الخط
Font-size تغيير حجم الخط
Margin تحديد المسافة الخارجية للعناصر
Background-color تغيير لون خلفية العنصر

الفرق بين HTML و CSS

تستخدم HTML في كتابة محتويات صفحة الويب وتحديد عناصرها الأساسية، بينما تستخدم CSS في التحكم في شكل هذه العناصر وتنسيقها. ويمكن القول إن HTML تبني الصفحة وCSS تعطيها الشكل المناسب.

الخاتمة

من خلال هذا البحث تعرفنا على لغة CSS ودورها في تصميم صفحات الويب، وتعلمنا أنها تساعد في تحسين مظهر المواقع وتنظيم محتواها. وتعتبر من اللغات المهمة التي يحتاج إليها كل من يريد تعلم تصميم وتطوير المواقع الإلكترونية.
